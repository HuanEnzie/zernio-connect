Zernio Connect

Dán một hoặc nhiều API key Zernio để tạo link kết nối tài khoản mạng xã hội, quét profile ID và account ID, và quét thông số video của từng kênh.

Kho API key

Key chỉ nằm trong trang này. Tải lại trang là mất, không được lưu ở đâu.
Mỗi key nối được tối đa 2 kênh. Kênh chưa có profile sẽ được tạo mới trên Zernio.
